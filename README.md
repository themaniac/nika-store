# NiKa Store

Landing page ufficiale per la prossima apertura di NiKa Store a Sambuceto.

## Sviluppo

```bash
npm install
npm run dev
```

La variabile `NEXT_PUBLIC_SITE_URL` deve contenere il dominio canonico di produzione su Vercel.
